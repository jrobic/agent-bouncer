# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| 1.4.0 | Yes |

## Reporting a Vulnerability

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/jrobic/agent-bouncer/security/advisories/new). Do not open a public issue for a vulnerability.

Expect an acknowledgement within 7 days. No remediation timeline is promised.

## Scope

Bouncer guards tool calls in the hook path. A bypass of a baseline rule is a vulnerability. A missing rule is a feature request; see [Add a custom rule](docs/how-to/add-a-custom-rule.md).
